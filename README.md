# Новогодний вечер

Сайт банкета на GitHub Pages. Каталог и программа хранятся в `docs/`. Планы, закрытые карточки, пожелания и история хранятся в одном проекте Supabase.

## Подключение Supabase

1. Примените `supabase/migrations/202611270001_banquet.sql` в отдельном проекте для банкета.
2. Выполните локальный `private/private-seed.sql` в SQL Editor. В нём исходные карточки 13 гостей. Каталог `private/` исключён из Git.
3. В Authentication оставьте включённым провайдер Email для внутреннего входа с паролем. Отключите самостоятельную регистрацию и внешние провайдеры, проверьте лимит попыток входа. Для подготовки учётных записей вычислите служебный адрес функцией `accountEmail` из `docs/login.js`. Создайте аккаунт через Supabase Auth Admin с `email_confirm: true` и паролем, обработанным функцией `loginPassword`. Служебный адрес нужен только Auth API. Гость вводит фамилию и номер, организатор — фамилию и отдельный стойкий пароль. Привяжите UUID каждого аккаунта к строке `public.guests`. Установите `admin=true` только организатору. Если две фамилии совпадают, согласуйте отдельные логины с инициалами.
4. В `docs/config.js` внесите URL проекта и ключ вида `sb_publishable_…`. В HTML и Git используют только этот публичный ключ.
5. В GitHub Pages выберите `main` и `/docs`. Проверьте пароль и ограничение прав с двух учётных записей, сохранение пожеланий, утверждение плана, синхронизацию и отсутствие закрытых данных до входа.

Фамилия преобразуется в служебный адрес. Пароли проверяет и хранит в виде хешей Supabase Auth. Список номеров храните отдельно от публичного репозитория. Все общие записи проходят серверную проверку. Только организатор публикует план. Участник видит собственные пожелания и карточку, список имён в рассадке и опубликованный план. Организатор видит все пожелания и исходные карточки. Общая история фиксирует утверждения. Полные версии плана доступны организатору. Realtime передаёт номер изменения, а приложение запрашивает данные с учётом роли. При недоступности Realtime данные проверяются каждые 20 секунд в открытой вкладке.
