# Новогодний вечер

Сайт банкета на GitHub Pages. Каталог и программа хранятся в `docs/`. Планы, закрытые карточки, пожелания и история хранятся в одном проекте Supabase.

## Подключение Supabase

1. Примените `supabase/migrations/202611270001_banquet.sql` в отдельном проекте для банкета.
2. Выполните локальный `private/private-seed.sql` в SQL Editor. В нём исходные карточки 13 гостей. Каталог `private/` исключён из Git.
3. В Authentication отключите регистрацию новых пользователей и создайте отдельные аккаунты для участников. Привяжите каждого пользователя к его строке в `public.guests` по UUID. Установите `admin=true` только на строке организатора.
4. В `docs/config.js` внесите URL проекта и ключ вида `sb_publishable_…`. В HTML и Git используют только этот публичный ключ.
5. В GitHub Pages выберите `main` и `/docs`. Проверьте вход и сохранение пожеланий гостем, утверждение плана организатором, обновление во второй сессии и отсутствие закрытых данных до входа.

Все общие записи проходят серверную проверку. Только организатор публикует план. Участник видит собственные пожелания и карточку, список имён в рассадке и опубликованный план. Организатор видит все пожелания и исходные карточки. Общая история фиксирует утверждения. Полные версии плана доступны организатору. Realtime передаёт номер изменения, а приложение запрашивает данные с учётом роли. При недоступности Realtime данные проверяются каждые 20 секунд в открытой вкладке.

Официальный каталог ресторана: [«Моя узбечка», Соколовая, 10/16](https://banquets.uzbechka.rest/menu). Цены сверены 27 ноября 2026 года. Лицензия клиентской библиотеки Supabase приведена в `docs/vendor/SUPABASE-LICENSE.txt`.
